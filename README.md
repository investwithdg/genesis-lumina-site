# Genesis Lumina Site

**Live site:** https://www.wearegenesislumina.com

## Overview
Marketing site for Genesis Lumina, guiding leaders on AI adoption and transformation. Includes program details, FAQs, and wayfinding content to help teams get started.

## Features
- Home landing with hero messaging and calls to action
- Programs overview with detailed program pages
- FAQ page addressing common questions
- Waypoints guides outlining steps for AI adoption

## Tech stack
- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui

## Local development
- Node.js and npm required
- Install dependencies: `npm install`
- Start dev server: `npm run dev`
- Build for production: `npm run build`
- Preview production build: `npm run preview`

## Deployment
Publish via [Lovable](https://lovable.dev/projects/77b4b35c-3557-4e99-93d2-451f78a483fa): Share → Publish. For a custom domain, go to Project → Settings → Domains and connect your domain.
